# Tempo

Application Android qui affiche la couleur EDF Tempo du jour et du lendemain,
le bilan de la saison, et envoie une notification le matin et/ou le soir.

## Télécharger

👉 **[Télécharger la dernière version (tempo.apk)](https://github.com/mdumont67/Application-Tempo/releases/latest/download/tempo.apk)**
## Installer

1. Ouvrir le lien ci-dessus depuis le téléphone et télécharger le fichier.
2. Ouvrir le fichier téléchargé. Si Android le demande, autoriser votre navigateur
   à « installer des applications inconnues ».
3. Si Play Protect affiche un avertissement : « Plus de détails » > « Installer quand même »
   (normal pour une application hors Play Store).
4. Pour recevoir les notifications à l'heure : Paramètres du téléphone > Applications >
   Tempo > Batterie > « Non restreinte ».

Données : [api-couleur-tempo.fr](https://www.api-couleur-tempo.fr).
